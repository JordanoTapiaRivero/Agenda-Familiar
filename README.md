# 🏠 Agenda Familiar

**Agenda Familiar** es una aplicación web desarrollada para facilitar la organización y coordinación de las actividades cotidianas de una familia desde un único lugar.

La aplicación permite administrar tareas, eventos, compras y gastos compartidos, manteniendo la información sincronizada entre los distintos integrantes de una familia.

## ✨ Funcionalidades principales

### 📊 Inicio

* Resumen general de la actividad familiar.
* Visualización de tareas pendientes.
* Próximos eventos.
* Listas de compras.
* Resumen de gastos.
* Acceso rápido a las distintas secciones.

### 📅 Calendario y eventos

* Creación de eventos familiares.
* Edición y eliminación de eventos.
* Organización mediante calendario.
* Visualización de próximas actividades.

### ✅ Tareas

* Creación de tareas familiares.
* Asignación y organización de tareas.
* Estados pendiente y completada.
* Eliminación automática de tareas completadas.
* Sincronización entre integrantes de la familia.

### 🛒 Compras

* Creación de múltiples listas de compras.
* Agregar productos y cantidades.
* Marcar productos individualmente como comprados.
* Seguimiento del progreso de cada lista.
* Listas activas y completadas.
* Eliminación de listas.

### 💰 Gastos

* Registro de gastos familiares.
* Descripción y monto de cada gasto.
* Organización y seguimiento de los gastos registrados.
* Edición y eliminación de registros.

### 👨‍👩‍👧‍👦 Familia

* Creación de un grupo familiar.
* Integrantes asociados a una misma familia.
* Información independiente entre diferentes familias.
* Datos sincronizados entre los miembros.

### 🔔 Notificaciones

* Centro de notificaciones dentro de la aplicación.
* Actualizaciones relacionadas con la actividad familiar.
* Notificaciones en tiempo real.
* Soporte para notificaciones Push en dispositivos compatibles.

### 🔐 Autenticación

* Registro de usuarios.
* Inicio y cierre de sesión.
* Sesiones persistentes.
* Información protegida por usuario y familia.

## 🔄 Tiempo real

Agenda Familiar utiliza sincronización en tiempo real para que los cambios realizados por un integrante puedan reflejarse en los dispositivos de los demás miembros de la familia.

Esto permite mantener actualizadas tareas, eventos, compras, gastos y notificaciones sin necesidad de actualizar manualmente la página.

El backend está desarrollado utilizando Supabase.

Se utiliza para:

* Autenticación de usuarios.
* Base de datos PostgreSQL.
* Gestión de familias y miembros.
* Almacenamiento de tareas.
* Eventos familiares.
* Listas y productos de compras.
* Registro de gastos.
* Sistema de notificaciones.
* Sincronización en tiempo real.
* Políticas de seguridad mediante RLS.

## 📱 Diseño responsive

La interfaz fue diseñada para adaptarse a diferentes tamaños de pantalla, permitiendo utilizar Agenda Familiar tanto desde computadores como desde dispositivos móviles.
